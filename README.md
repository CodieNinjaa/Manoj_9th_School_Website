# Bapu Primary & High School - Web Project

## Project Overview

This project is a modern, responsive landing page designed for **Bapu Primary & High School**. It was developed to showcase the school's facilities, mission, and admission process through a clean and interactive user interface.

**Created By:** Manoj M

**Class:** 9th Standard, Section 'A'

**Institution:** Bapu School

**Guide:** Shivam Kumar S

**Purpose:** Curriculum Project

---

## Key Features

* **Responsive Design:** Optimized for both desktop and mobile viewing using CSS Flexbox and Grid.
* **Dynamic Countdown:** A real-time JavaScript timer located in the Admission section counting down to the enrollment deadline.
* **Interactive Navigation:** A sticky navigation bar for easy access to different sections of the page.
* **Visual Media:** Includes a video hero background and a campus image gallery.
* **Functional Forms:** A built-in admission inquiry form and a commented-out student login module for future scalability.
* **Google Maps Integration:** An embedded map to help parents and visitors locate the campus easily.

## Project Structure

* `index.html`: The main entry point containing the site structure.
* `stylesheet.css`: Contains all visual styling, color schemes (Orange/Blue theme), and layout rules.
* `script.js`: Handles the admission timer logic and login functionality.

---

## How to Run the Project

1. Ensure all three files (`index.html`, `stylesheet.css`, and `script.js`) are in the same folder.
2. Place the required assets (like `BG_VIDEO.mp4` and images) in the same directory or update the file paths.
3. Open `index.html` in any modern web browser (Chrome, Firefox, or Edge).
